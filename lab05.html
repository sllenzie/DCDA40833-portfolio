Vibe Coding

Introduction

I successfully got the error message stating I ran out of credits to use the CoPilot model that I was working with. That wasn’t the goal, but it happened anyway. The goal was to make my homepage, and all the other pages, of my portfolio as user-friendly and smooth as possible, with adding a hamburger menu bar that was sticky for mobile users, a carousel full of images of me at various professional events, and a back-to-top widget that appears at a certain point of the page, and is on the same layout throughout. I know, that sounds like a lot, and it was to do all at once with the troubleshooting, babysitting, and editing that is necessary for this portfolio to actually be usable.

Menu Bar

For the menu bar, it was a quick fix, and to make it sticky all I needed to change was to literally write position: sticky in the CSS script. The latter, I knew already based on previous coding experience, so that was one of the only things I did not use the CoPilot agent for. Everything else with the hamburger menu, I knew exactly what I was asking for, and once the code was written I can explain it as well as point it out when looking for specific devices, but it takes me significantly longer to write it on my own, and there is a much larger probability for error.

Carousel

The carousel of images was about half new to me and half not. I was incredibly familiar with placing images on a site, as that might have been one of the first things that I learned when I was picking up coding for the first time, but adding multiple in a carousel that was automatically timed was brand new. I have definitely encountered it before in everyday life, through other websites, and I find it to be an endearing and a cool thing for the average visitor to my site. Or recruiters, it might help with that too. As for how it works, it makes sense if I really squint at the HTML and CSS. It makes sense that there’s a new specialized class called “carousel” and everything beneath it was all discussing the carousel. It also makes perfect logical sense that there’s a separate button class called, “carousel-button” and so on. Something that I did not specifically ask for, but was implemented anyway, was the inclusion of aria labels that are for better accessibility access, which I did appreciate. Honestly, it made me want to include it in the rest of the site, once my tokens reset of course, so I could get a better explanation of the proper syntax and not break everything all at once.

However, one of the things I definitely would not have been able to include on my own was the JavaScript file that was responsible for the timing between the pictures. More than that, it is the language that I am admittedly the least familiar with and that makes the least sense to me, so I really don’t know what all I’m looking at. I can make an educated guess as to the correct functions of various areas, and some of it feels like common sense, but this is where we dip into the territory of being much more of a novice than I am with the other coding languages that are used heavily in my website. Sure, I can guess that the commands “let autoplayInterval; const autoplayDelay = 5000” means that there are five seconds in between slides of the carousel, but there is no way I would have been able to write that code on my own. 

let currentIndex = 0;
let autoplayInterval;
const autoplayDelay = 5000; // 5 seconds between slides

// Autoplay function
const startAutoplay = () => {
    autoplayInterval = setInterval(() => {
        moveSlides('next');
    }, autoplayDelay);
};

const stopAutoplay = () => {
    clearInterval(autoplayInterval);
};

There was a bit of troubleshooting that took up most of the tokens. When I initially added the carousel of images, I did not have additional images to add yet. I needed to go through my files and figure out which ones I wanted to showcase! I had figured that I could copy the code that was already implemented in the file, with the new filepath of the new image and it would work perfectly! I was wrong. I went over the HTML with a fine tooth comb, thinking I had missed a space or a dash somewhere, but the code was identical in the HTML. I turned to the CSS next, thinking there was some sort of styling issue, but everything looked like it should. I turned to the troubleshooting, and after half-dozen back and forth, the issue was the file size. The new image I wanted to showcase was three times the size of the first image, so it wasn’t loading in the browser window. Of course, it took us a very long time to reach that conclusion together, but it works now!

Back to Top Button

The other item that I specifically added was the “back to top” button, but I was able to style that within the HTML and CSS myself thanks to previous work. Again, the point where I specifically asked for help was with looking at the JavaScript styling for the small animation of the arrow and when it would appear once the user had scrolled to a certain point. There was no troubleshooting necessary for this, since I was giving the AI an incredibly specific task. Simply look in the bottom right corner of the browser window to see the button appear and disappear!

// Show/hide button based on scroll position
window.addEventListener('scroll', function() {
    if (window.pageYOffset > 300) {
        backToTopButton.classList.add('visible');
    } else {
        backToTopButton.classList.remove('visible');
    }
});

// Smooth scroll to top when clicked
backToTopButton.addEventListener('click', function() {
    window.scrollTo({
        top: 0,
        behavior: 'smooth'
    });
});

Conclusion

After this, I can definitely see the issues that AI might raise. I knew what o ask for and what to look for because I have worked with various coding languages in the past, though I am by no means an expert. Because of this, I knew how to word my prompts, and when to look specifically for errors that the agent might make. However, if I didn’t know this, then I can absolutely see how it could turn much more ethically grey. Personally, I’ll stick to using AI when specifically told to by my professors, and almost exclusively in a coding environment, because I find it more satisfying when I can point at a piece of work and say that I made it entirely with my thoughts and skills. I predict that will be fewer and further in between as the AI boom continues to progress.
